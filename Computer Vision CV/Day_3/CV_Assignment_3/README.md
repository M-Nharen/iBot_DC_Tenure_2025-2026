# Cat-Dog Detector

This is a Python script used to detect classify images as either cats or dogs.

## Overview:

This directory contains all the necessary steps to setup and run the train.py and evaluate.py

```
Directory  Structure

CV_Assignment_3/
├── best_model.pth
├── confusion_matrix.png
├── evaluate.py
├── README.md
├── train.py
└── training_curves.png
```

## Setup:

The program requires the following libraries:

```
1.torch
2.numpy
3.matplotlib
4.seaborn
5.sklearn
```
## Usage:

To train the model to get a new model run

```
python3 train.py
```

## Testing:

To test the model save it as best_model.pth and then run the evaluate script as given before

```
python3 evaluate.py
```
